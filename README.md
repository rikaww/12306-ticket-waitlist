# 模拟 12306 车票候补系统 (基础版)

本项目为数据结构课程实践大作业，使用标准 C++ 实现 12306 车票候补模块的核心业务流。

## 一、项目设计思路
根据 12306 候补购票规则，旅客在无余票时提交候补订单排队，放票时按照提交先后顺序从队头依次分配。该业务场景本质上是**先进先出（FIFO, First In First Out）**的线性数据结构，故采用标准队列 `std::queue` 进行实现。

## 二、模块实现功能
1. **新增候补订单 (入队)**：旅客录入姓名、身份证号及所需票数后，分配唯一订单编号并插入队列末尾。
2. **余票发放与兑现 (出队)**：系统输入本次释放余票数 $k$，从队头依次处理，满足票额后订单出队并打印兑现凭证，同时扣减余票数。
3. **余票为 0 状态检查**：当余票耗尽时判断队列是否为空；若不为空则展示队伍中保留等待的订单明细，并遵循新订单入队尾的规则。
4. **控制台防刷交互**：加入回车暂停响应机制，确保交互信息清晰可见。
